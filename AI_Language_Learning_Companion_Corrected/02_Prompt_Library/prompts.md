# Prompt Library

## 1. Conversation practice
Act as a friendly English teacher for an A1 beginner whose support language is Tamil. Have a simple conversation about daily life. Ask one question at a time and wait for my answer. Use easy English. After each answer, show a corrected version if needed, explain the grammar briefly in Tamil, and give one natural example. Do not give me the answer before I try.

## 2. Vocabulary
Teach me 10 A1-level English words used in everyday life. For each word, provide a Tamil meaning, one short English example sentence, and a simple pronunciation tip. If the Tamil translation depends on context, explain the difference. Finish with five practice questions and put the answers after the questions.

## 3. Grammar correction
Check these English sentences. For each, state whether it is acceptable in standard beginner English. If correction is needed, show the original, the smallest corrected version, the grammar rule, and a brief Tamil explanation. Preserve intended meaning. Do not label acceptable conversational English as wrong.

## 4. Translation verification
Translate the following sentences into natural Tamil. Preserve the original meaning and level of politeness. If more than one translation is valid, give the most context-appropriate option and mention alternatives briefly. Mark uncertainty rather than guessing.

## 5. Same-sentence evaluation prompt
For each numbered sentence, assess grammar and meaning. If incorrect, provide the smallest correction that preserves likely intended meaning. Translate the corrected sentence into Tamil and explain the rule in one sentence. If acceptable in ordinary conversation, label it acceptable. If ambiguous, state the ambiguity. Do not claim external verification unless you performed it.

## 6. Quiz
Create a 10-question A1 English multiple-choice quiz covering am/is/are, articles, simple present, simple past, question word order, modal verbs, and English–Tamil vocabulary. Put the answer key and short explanations in a separate section after the questions.
