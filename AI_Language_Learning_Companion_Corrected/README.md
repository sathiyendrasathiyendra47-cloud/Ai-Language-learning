# CAPSTONE 4 — AI Language Learning Companion for Beginners
**Target language:** English | **Level:** A1 beginner | **Support language:** Tamil | **Duration:** 14 days

## Research question
Can free AI tools act as a safe and accurate practice partner for basic English conversation?

## Contents
1. Practice plan (14 days)
2. Prompt library
3. Ten common test sentences
4. Mistake log with 30 blank test records
5. English–Tamil vocabulary sheet
6. Ten-question quiz and answer key

11. Final demo outline

Check current free-tier limits and terms before use.

## Workflow
Complete the Day 1 baseline, follow the plan, test the same sentences with three AI tools using the same prompt, record actual outputs, independently verify corrections/translations, collect audio evidence, create and proofread the poster, then compare Day 14 results with Day 1.

**Integrity note:** This archive contains templates and sample learning material, not fabricated test results, audio recordings, or a finished poster. Complete these activities and save evidence before submitting.
